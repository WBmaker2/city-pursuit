# 위반 발생 후 경찰 추격 — 변경 계획

2026-09-08

## 요청과 동작
처음에는 추격 없는 자유 주행. 과속 또는 플레이어가 움직이며 다른 차량에 충돌했을 때만 추격 시작. 시작 알림에는 위반 사유를 명시한다. 추격 중 경찰과 42m 넘게 떨어져 10초를 연속 유지하면 추격 해제. 거리가 다시 좁혀지거나 새 위반이 발생하면 도주 시간이 초기화된다. 해제 뒤 경찰은 더 이상 플레이어 경로를 추적하지 않는다. 새로운 위반은 다시 추격을 시작할 수 있다.

## 게임용 위반 규칙
실제 도로 법규를 모사하는 법률 설명이 아닌 게임 규칙이다. 화면 표시 속도 기준 제한 120km/h를 1.5초 연속 초과하면 과속. 단일 과속 구간은 한 번만 신고하고 제한 속도 이하로 복귀한 뒤 새 과속 구간에서 재신고한다. 움직이는 플레이어의 차량 충돌은 사고 신고. 서 있는 플레이어에게 NPC가 들이받는 경우는 범죄로 판정하지 않는다. 벽/경계/핸드브레이크만으로는 신고하지 않는다.

## UI와 상태
명확한 wanted 상태(추격 없음/추격 중/도주 중), 위반 사유, 눈에 띄는 추격 시작 알림, 10초 남은 시간과 경찰 접근 시 리셋 안내. 추격 해제 메시지 후 자유 주행 계속. 체크포인트는 기존 순서를 유지하고 모두 통과 + 추격 없음일 때 성공한다. 모든 체크포인트를 통과하지 않아도 추격은 독립적으로 해제 가능하다. 일시정지/도움말/포커스 해제는 타이머도 멈춘다. 재시작은 wanted, 알림, 과속 누적, 타이머와 차량 상태를 모두 초기화한다. 모바일에서도 추격 알림과 타이머가 조작 버튼을 가리지 않게 한다. 업데이트 내역에 변경 기록.

## 작업과 검증
부모가 계획/리뷰, gpt-5.6-luna가 코드/테스트/릴리스。파일 500줄 이하. 기존 생성 텍스처 유지. 상태 전환을 단위 테스트하고 빌드된 프리뷰에서 실제 입력과 진단 상태로 초기 평화/과속 발동/알림/타이머/재접근 리셋/해제/재추격/재시작 확인. ego-browser의 이전 raster 캡처 실패를 반복하지 않고 DOM/상태/캔버스 위치로 검증한다. VoiceOver 제외. 검증 후 기존 공개 Pages에 업데이트하고 URL을 보고한다.
