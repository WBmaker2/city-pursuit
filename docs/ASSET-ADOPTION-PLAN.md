사용자가 새 후보의 도로, 건물 외벽, 차량 도장, 체크포인트 데칼을 선택했다.

- 비교 폴더의 candidate-atlas.png를 버전 있는 공개 에셋으로 복사하고 기존 사분면 머티리얼 로딩에서 사용한다. 기존 원본과 비교 후보는 보존한다.
- checkpoint-decal.png를 공개 에셋으로 복사하고 도로 바로 위 평면에 적용한다. 투명 배경, 깊이 충돌 방지, 과도한 발광 방지, 다음 목표 표시와 통과 후 숨김을 확인한다.
- 데칼 화살표는 체크포인트 경로 방향에 맞추고 원근 카메라에서 식별 가능하게 한다. 머티리얼/텍스처는 공유한다.
- 업데이트 내역과 이미지 출처를 기록한다. Images 2.5라고 확인되지 않은 모델명을 사용 사실로 표시하지 않는다.
- 부모는 계획/리뷰/브라우저 QA, gpt-5.6-luna는 구현/테스트/커밋/푸시/Pages 배포를 담당한다. 파일당 500줄 미만 유지.
- 기존 38개 테스트와 빌드, 프리뷰에서 에셋 로딩/투명도/체크포인트 진행/주행 확인 후 배포하고 공개 URL에서도 확인한다. VoiceOver 및 실패한 래스터 캡처 반복은 제외한다.
