# 넓은 도로와 우측통행, 밝기 개선

2026-09-09

## 목표
양방향 차량이 각자의 우측 차로로 지나가며 충돌하지 않도록 도로와 교통 경로를 함께 수정한다. 도시와 차량의 시인성을 높인다.

## 설계
- 도로폭을 현재 8에서 약 12로 확대하고 차로 중심을 도로 중심에서 약 3만큼 떨어뜨린다. 차량 충돌 반경, 차체 폭과 건물 여유를 검토해 최종 수치를 맞춘다.
- 렌더링, 주행 가능 범위, 건물 배치/충돌 크기, 물리 shape cast를 동일한 공통 치수로 정리한다. 차로 간격은 기존 차량 충돌 거리보다 넓게 한다.
- 일반 차량의 진행 방향에 따른 우측 벡터를 사용해 차로를 배치한다. 양방향 교통을 구성하고 경계 재등장 및 충격 후에도 올바른 차로로 회복한다.
- 경찰의 교차로 접근/회전/추격 경로를 우측 차로에 맞춘다. 플레이어 위치로 무조건 도로 중앙/반대 차로를 가로지르지 않는다. 플레이어 초기 위치도 우측 차로로 맞춘다.
- 기존 충돌 회피, 밀어내기, 추격/도주, 체크포인트 판정을 보존한다. 넓어진 차로에서 체크포인트를 정상 통과하도록 크기와 표식을 조정한다.
- 하늘·안개·환경광과 텍스처 곱색을 조정해 밝은 늦은 오후 도시로 만든다. 새 에셋은 그대로 사용한다.
- 업데이트 내역을 추가한다. 부모는 계획/리뷰/브라우저 QA, gpt-5.6-luna가 구현·검증·커밋·배포한다. 코드 파일당 500줄 미만을 유지한다.

## 검증
양방향 교행에서 간격/무충돌/진행을 확인한다. 방향별 우측 차로, NPC 재등장, 경찰 직진·회전·추격 복귀, 건물 경계와 도로폭 일치, 체크포인트 양차로 통과, 기존 테스트를 확인한다. ego-browser에서 실제 키 주행과 진단 시나리오를 구분해 검증한다. 래스터 캡처 실패 반복 및 VoiceOver는 제외한다. 밝기는 조명/재질 상태 검증의 한계를 밝힌다. 기존 Pages에 배포 후 공개 버전을 확인한다.
