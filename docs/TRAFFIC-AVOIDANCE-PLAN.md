# NPC 차량 충돌 회피 개선 계획

2026-09-08

## 목표
일반 차량이 플레이어와 다른 차량을 감지해 충돌을 예방한다. 플레이어가 일부러 끼어들거나 들이받는 상황까지 무조건 무충돌이라고 주장하지 않는다. 기존 운전 조작, 체크포인트와 위반 후 경찰 추격 규칙은 유지한다.

## 알고리즘
- 현재 프레임의 차량 위치/속도를 스냅샷으로 모아 모든 NPC가 같은 상황을 보고 판단한다.
- 차량의 고유 진행 방향과 순항 속도를 별도 유지하여 정차 뒤 정상적으로 재출발한다.
- 전방 차간 거리, 상대 속도, 짧은 시간 뒤 예상 충돌 지점을 계산하여 미리 감속하고 가까우면 비상 정차한다. 플레이어와 정지 경찰도 장애물로 감지한다.
- 교차 진로는 플레이어 우선, 이미 교차 구역 안의 NPC 우선, 동률은 안정적인 차량 ID 우선으로 양보한다. 양쪽이 영구 정차하지 않도록 통과/재출발을 검증한다.
- 회피 조향은 경로 전체가 도로 안이고 건물/다른 차량과 안전 간격을 확보할 수 있을 때만 허용한다. 좁은 도로에서는 무리한 우회보다 정차한다.
- 최종 이동 구간에 연속 충돌 검사를 적용해 한 프레임 이동으로 다른 차를 관통하거나 겹치지 않게 한다. 화면 끝 재등장 위치가 점유됐으면 대기한다.
- 플레이어가 이동 중이라는 이유만으로 NPC가 일으킨 접촉을 플레이어 범죄로 신고하지 않는다. 접촉 직전 속도와 접근 방향을 확인한다. 플레이어가 정지 NPC에 실제로 들이받는 경우의 피해/신고는 유지한다.

## 구현/검증
부모는 계획·리뷰·브라우저 QA, gpt-5.6-luna가 구현·테스트·배포. traffic-ai 모듈과 별도 테스트 파일로 분리하고 파일당 500줄 미만 유지. UI는 기존 업데이트 내역에 변경만 기록한다. 생성 이미지와 조작 UI는 유지.

정지 플레이어 앞 제동, 움직이는 앞차 추종, 갑작스러운 감속, NPC 교차로 양보와 통과, 정면 접근, 정차 후 재출발, 점유된 경계 재등장, 여러 NPC 장시간 안전 간격, 의도적인 플레이어 충돌 판정 및 기존 경찰 규칙 회귀를 테스트한다. 동일 진단 시나리오를 빌드된 프리뷰와 공개 배포본에서 확인한다. ego-browser의 기존 raster 캡처 실패를 반복하지 않고 DOM/시뮬레이션 상태를 이용한다. VoiceOver 제외. 검사 후 기존 GitHub Pages에 반영한다.
