# 미니맵 일반 차량 표시

2026-09-08

## 목표
운전자가 일반 차량의 위치와 진행 방향을 미리 확인하도록 미니맵에 모든 NPC 차량을 실시간 표시한다.

## 구현
- 기존 도로, 체크포인트, 경찰, 플레이어 표시를 유지한다.
- 일반 차량은 밝은 하늘색 방향 표시로 그리고, 기존 청록색 플레이어 및 경찰과 색상/모양으로 구분한다. 겹칠 때 플레이어가 위에 보이도록 한다.
- 미니맵 바로 아래에 작은 범례를 추가하고 모바일에서도 주변 HUD를 가리지 않도록 한다.
- 게임 내 업데이트 내역을 추가한다. 기존 주행/추격 로직은 변경하지 않는다.
- 부모는 계획/리뷰, gpt-5.6-luna가 구현 및 커밋/배포를 담당한다. 파일당 500줄 미만 유지.

## 검증 및 배포
기존 테스트와 빌드를 실행한다. ego-browser에서 실제 canvas 그리기 호출과 게임 상태를 비교하여 NPC 전체 표시 및 이동 반영을 확인하고, 작은 화면의 범례/HUD 배치를 확인한다. 기존 캡처 도구 실패를 반복하지 않으며 VoiceOver는 제외한다. 검증 후 기존 GitHub Pages에 배포하고 공개 URL을 확인한다.
