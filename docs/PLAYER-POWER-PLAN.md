# 플레이어 속도 및 돌파력 개선

2026-09-08

## 목표
플레이어가 일반 차량과 경찰보다 빠르게 가속/주행하고, 정면으로 차량을 밀어내며 탈출할 수 있도록 한다. 기존 추격 시작/도주 타이머와 교통 회피 규칙은 유지한다.

## 구현 방향
- 현재 최고속도, 경찰 추격 속도, 가속 및 마찰을 먼저 비교한다. 실제 도달 가능한 일반 최고속도부터 경찰보다 충분히 높게 하고 Shift 부스트는 추가 우위를 준다.
- 차량 간 접촉의 일률적인 플레이어 역방향 반사를 제거한다. 접근 속도와 방향에 따라 플레이어의 전진 운동량을 유지하면서 상대에게 밀려나는 속도를 전달한다.
- NPC/경찰 AI가 다음 프레임에 밀림을 덮어쓰지 않도록 짧은 외부 충격 상태를 따로 적용하고 감쇠한다. 건물과 경계 충돌을 보존한다.
- 반복 접촉 시에도 가속으로 서서히 밀고 나올 수 있도록 하되 정지 접촉에서 무한 추진력이나 순간이동을 만들지 않는다.
- 기존 피해/위반 신고, 후방 추돌 귀책, NPC 회피와 경찰 복귀 규칙을 유지한다. 충돌 판정과 추진력이 피해 쿨다운에 묶이지 않도록 한다.
- 도움말/업데이트 내역을 갱신한다. 부모는 계획/리뷰, gpt-5.6-luna가 구현/테스트/배포, 코드 파일은 500줄 미만으로 유지한다.

## 검증
일반 가속과 부스트 실제 속도 우위, NPC/경찰 밀어내기와 여러 프레임 지속, 저속 접촉 재가속 탈출, 건물/경계 보존, 기존 교통/경찰 회귀 테스트를 실행한다. ego-browser에서 실제 키 주행과 진단 충돌을 구분해 검증한다. 캡처 실패 반복과 VoiceOver는 제외한다. 기존 Pages에 배포 후 공개 게임을 확인한다.
