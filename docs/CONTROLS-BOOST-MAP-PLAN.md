# 안내 버튼, 속도 제한, 방향 미니맵

2026-09-09

- 조작법 안내와 업데이트를 별도 버튼/콘텐츠로 분리한다. 모달 열기 전 실행 상태를 기억하고 닫기/ESC 시 적절히 복귀한다. 클릭과 키 입력이 중복 실행되거나 모달 중 차량이 움직이지 않도록 한다.
- 일반 NPC 순항 8~10 기준 플레이어 일반 최고속도를 12(표시 96km/h) 정도로 제한한다. 부스트는 기존 최고속도 34까지 실제 도달할 수 있는 가속력을 부여한다. 부스트 해제 후 일반 제한으로 돌아가며 제동과 충돌 돌파는 유지한다. 기존 과속 한도와 추격 규칙은 유지한다.
- 미니맵 플레이어/경찰도 실제 heading을 따라가는 화살표로 표시한다. 색상/크기와 그리기 순서로 플레이어를 우선 구분하며 범례도 맞춘다.
- 업데이트 내역을 기록하고 파일당 500줄 미만으로 필요한 UI 로직을 분리한다. 부모는 계획/리뷰/QA, gpt-5.6-luna가 구현·테스트·커밋·배포를 담당한다.
- 실제 버튼 열기/닫기/ESC/일시정지 상태, 모바일 버튼 배치, 일반 속도/부스트 도달/해제, 기존 주행 회귀 및 미니맵 방향 그리기를 검증하고 Pages에 배포한다. VoiceOver는 제외한다.
