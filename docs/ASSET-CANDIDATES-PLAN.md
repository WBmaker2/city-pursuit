# 에셋 비교 후보 제작

2026-09-09

- 현재 city-atlas.png와 기존 라이브 게임을 보존한다. 사용자 선택 전에는 교체하거나 배포하지 않는다.
- ChatGPT 내장 image_gen으로 새 2x2 아틀라스 후보를 생성한다. 요청 모델명 Images 2.5는 도구가 버전 선택/확인 기능을 제공하지 않으므로 보장하지 않는다.
- 기존 도로/외벽/차량 도장/레퍼런스 순서를 유지해 비교한다. 새 후보는 반복 패턴과 도로 판독성을 우선한다.
- 추가 후보는 체크포인트 바닥 유도 데칼로 만든다. 새 게임 기능이나 적용을 완료했다고 주장하지 않는다.
- 후보와 기존 이미지를 나란히 보는 로컬 비교 페이지, 원본 이미지, 프롬프트/제약 설명을 제공한다. 이미지 생성은 내장 도구, 비교 페이지와 파일 처리는 gpt-5.6-luna에 위임한다.
- 이미지 생성 결과를 직접 확인한다. 비교 페이지는 프로덕션 소스에서 분리하고 반영 전 선택을 기다린다.
